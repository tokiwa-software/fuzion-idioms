Idiom # 180: List files in directory

See programming-idioms.org:

Code

io.dir.traverse collects the entries of directory d into a list. It starts with an empty Sequence [] and appends each entry p. Setting the argument to false disables descending into subdirectories. The result x is an outcome (Sequence io.path), returning an error if the directory fails to open.

The order of the entries is not defined, it depends on the file system.
